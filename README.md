🧮 Projeto Calculadora de IMC
Esse é um projetinho simples que fiz usando React. Ele serve pra calcular o IMC da pessoa, com base na altura e no peso informados.

Você digita sua altura (em metros, tipo 1,70) e seu peso (em kg), e o sistema já calcula na hora o seu IMC. Também coloquei botões de setinha pra aumentar e diminuir os valores direto na interface, sem precisar digitar.

🛠 Tecnologias usadas
* React
* Vite
* TailwindCSS

🚀 Como rodar o projeto
Abrir VS Code com Node instalado na máquina e fazer os seguintes comandos:
npm install
npm run dev

Depois é só abrir no navegador e usar a calculadora.
